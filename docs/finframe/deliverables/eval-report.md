## 4. 方法与口径说明

1. 每个实验只改一处，测 seed ×2 + planning ×2 + prompt ×2，单独决定保留或回退。
2. 根因只写「假设」。例如 E1「playbook 要求写关键数字」是未证实的假设，数据只显示方向一致。
3. 评分器的误判在发现后修正，存档本身不改；所有组用同一套评分器重算。M2 期间修了数字误判（解释口径、覆盖度计数等）和拒答漏判（「没法 / 做不了」），见 `b1125b8`。
4. 发现过的评测缺陷都如实记录：
   - M1–M4 的种子夹具计划文案缺陷（`0f2d785`），修复前后的分数不混用；
   - 评测运行器 max_tokens 截断被当成空回答（`190989c`）。
