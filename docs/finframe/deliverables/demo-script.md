# FinFrame Demo 脚本（草稿，2026-10-09）

**环境**：

- 本机 `npm run start -w @opptrix/server`（:8711）+ `WEB_HTTPS=0 npm run dev`（:5173）
- 默认对话优先布局、Composer 开
- 模型 deepseek-flash
- 演示前清空看板，或新建会话

**每步的依据**：脚本化重放与计时记录 `eval/finframe/m5/records/2026-10-09T21-42-18-667Z-pacing.json`（commit `6b749bf`）。

## Demo A：两家公司的盈利能力对比（约 1 分钟）

1. 输入「对比贵州茅台和五粮液最近五个已披露完整财年的净利率与 ROE。」
2. 约 8 秒：回答里先出现两张预览卡（净利率、ROE）。约 12 秒：被一份活报告替换，内容是对比图、走势、来源与口径（M5 中位数，C3）。
   - 讲解点：正文不写具体数字；图里的每个数字都可以点开看来源和报告期。
3. 点趋势组件上的「看变化最大的年份」：立即显示「由代码计算：……较上年 ±X 个百分点」，不再发起一轮对话。
4. 在组件里把图种切到「表格」，再点「钉住」：看板计数 +1。打开看板，看到的是表格视图。
   - 讲解点：钉住之前看板不会变，AI 不能自己写看板。

## Demo B：多轮追问（约 1.5 分钟）

1. 接着 Demo A 输入「只看近三年，为什么其中一家的净利率变化比另一家更明显？」
2. 约 25–30 秒：Agent 沿用上一轮的公司，派生近三年的数据集（refine，不重新取数）。回答把「数据证实」和「待调查原因」分开写，走势说法来自代码给出的标签（M2-E2）。
   - 讲解点：如果用户的说法和数据不符，Agent 会先纠正。M2 的 ff-005 例子里，用户问「为什么下滑」，数据其实是先降后升，回答先指出了这一点。
3. 点「调整」：这张图作为上下文带到输入框，用户说明想怎么改。

## Demo C：歧义、缺数、不可用（约 1.5 分钟）

1. 输入「比较苹果和腾讯控股 2020 到 2024 年营收」：一次调用后直接说明美股、港股暂不支持，并给出可改查 A 股的方向。没有反复重试，也没有网页搜索（M2-E3）。
2. 输入「看贵州茅台 2026 年全年净利率」：说明 2026 年报尚未披露，可以先看 2021–2025。
3. 输入「招商银行近五年毛利率」：说明银行没有毛利率这个口径，不补值。

第 2、3 步的依据是 seed-v2 的 v2-20、v2-22（评测夹具；记录见 `docs/finframe/seed-v2-report.md`），**还没在实时应用里核对过**，演示前先在本机实际跑一遍。
4. **暂时不要演示**「看一下平安近五年的 ROE」：当前解析器会直接选中国平安、不澄清（M5 发现，待修）。
