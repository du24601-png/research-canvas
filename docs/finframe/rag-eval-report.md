# 文档知识库检索评测报告（2026-10-10）

评测脚本 `eval/rag/`（`npm run eval:rag`），原始记录 `eval/rag/records/2026-10-10T11-01-52-975Z.json`。语料与中间数据在 `D:\finframe-data\`（不进仓库）。相关提交：`a110af3`（trigram）、`59408ec`（模型清单）、`83a3f74`（评测）。

## 结论

1. **trigram 迁移效果最大**：用关键词检索时，前 10 条命中答案页的比例从 0.25 提到 0.94（不含招商银行）。这一项不需要任何模型，已经完成。
2. **默认向量模型推荐 bge-small-zh-v1.5，不推荐 Qwen3-0.6B 做默认**：两者和 trigram 组成混合检索后命中率一样（0.977）；Qwen3 只在「用户原话直接检索」时略好（0.645 对 0.591），但入库慢 50 倍（6 份年报 1655 秒对 33 秒）、内存 3.1 GB 对 0.9 GB。Qwen3 适合做可选的「高质量」档。
3. **发现一个严重的产品问题**：现有的 PDF 解析几乎读不出招商银行年报里的中文（362 页里只有 3 页超过 100 个汉字）。用户今天上传这份年报，什么都搜不到。仓库里已有的另一个 PDF 库（pdfium）能正常读出来。
4. **用户原话直接搜，关键词检索命中为 0**：一整句中文没有空格，被当成一个词组去匹配。现在完全依赖 agent 先把问题改写成关键词。
5. **向量检索没法判断「文档里没有」**：没有答案的问题也总会返回结果，相似度分数和有答案时重叠，定不出阈值；关键词检索在这类问题上正确返回空。

## 评测设计

- **语料**：6 份 2024 年年报（贵州茅台、宁德时代、比亚迪、美的集团、招商银行、中国平安），来自巨潮资讯网，共 39 MB，地址与 sha256 见 `D:\finframe-data\eval-corpus\manifest.json`。
- **入库**：走产品自己的文档库服务，切块方式与线上一致（约一页一块，共约 1666 块），每种配置用全新数据库。
- **题集**：144 题 = 6 份 × 20 题 + 12 道跨公司 + 12 道无答案。题型：指标定位 18、原因解释 24、展望与计划 18、风险因素 18、表格定位 22、同义口语 20。每题标注答案页，并自动核对证据原文确实在该页。
- **两种问法**：用户原话、agent 风格的关键词改写，每种配置都跑。
- **指标**：前 5 / 前 10 条命中答案页的比例（Recall@5 / @10）、平均排名倒数（MRR@10）、nDCG@10、延迟、内存、索引大小。

## 局限（读数时要打折）

- 关键词改写是看过原文后写的，借用了年报里的措辞，**关键词一栏是上限**，真实 agent 改写会低一些。
- e5（当前默认模型）本机没有，没测；需要的话把模型放到 `D:\finframe-data\models\multilingual-e5-small` 后运行 `node eval/rag/run.mjs e5`。
- 招商银行的题按 pdfium 读出的文本出题，页码与产品一致，但产品当前读不出这份文件，所以单列。
- 每份年报一块约一页（1000–2800 字），超过 bge 的 512 token 上限，长页后半部分没有进向量。

## 建议（按优先级）

| # | 做什么 | 为什么 | 改动 |
|---|---|---|---|
| 1 | **PDF 解析兜底**：中文占比异常低时改用 pdfium，或转 OCR | 招商银行这类年报现在完全搜不到 | doc-library 解析层 |
| 2 | **默认开启混合检索，默认模型换成 bge-small-zh**；Qwen3 作为可选高质量档 | 混合检索 0.977，bge 成本只有 Qwen3 的几十分之一 | 配置 + 已有模型清单；需要回填向量 |
| 3 | **用户原话也能走关键词检索**：中文整句按 3 字切片后用 OR 匹配，按 bm25 排序 | 现在原话命中 0，全靠 agent 改写 | fts-cjk 查询构造 |
| 4 | **切块变小**：约 400–600 字、带少量重叠，表格行不拆 | 解决 512 token 截断，向量命中率预计会涨 | 切块参数 + 回填 |
| 5 | **跨公司问题按公司分别检索再合并** | 跨公司题最弱 | 检索工具或提示词 |
| 6 | **「文档里没有」的判断**：关键词无命中且向量最高分低于参考线时，提示「资料里可能没有」，由模型确认 | 向量永远有结果 | 工具结果加信号 |
| 7 | 改完 1–4 后重跑本评测；关键词改写改成「不看原文」写的版本 | 去掉乐观偏差 | 评测脚本 |

第 1、2、4 项会改数据结构或需要回填已有资料，按 AGENTS.md 先确认再做。
