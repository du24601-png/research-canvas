# FinFrame 用户价值：便利、清晰、辅助决策（2026-10-10）

起点：Quinn 问「到底有什么独特的交互和功能，能和通用 AI 区别开」，并要求从**用户使用便利、清晰、辅助决策**三个角度想。本文只讨论产品方向，不改代码。标注「已有」的都能在代码里找到，「新做」的是提议。

## 用户是谁、要完成什么

主要用户：自己做研究的 A 股投资者 / 研究员。他们反复做的几件事：

1. **看一家公司变好还是变坏**（盈利能力、增长的走势）。
2. **和同行比**：它在行业里处于什么位置。
3. **核对一个数**：报告、新闻里的数字对不对，是什么口径。
4. **跟踪手里的股票**：新财报出来后，有什么值得注意的变化。

通用 AI 在这四件事上的共同问题：数字不可信、口径不清、每次都要重新问、给出一段话而不是能比较的结构，最后还容易给出「建议买入」这类越界的话。

## 1. 便利：少打字、少等待、少重复

| 交互 | 解决什么 | 状态 |
|---|---|---|
| **从自选 / 持仓出发**：首页显示「你的自选里本周有 3 家发布财报」，一点生成对比 | 不用想怎么提问 | 新做（自选、持仓数据已有） |
| **歧义一键选**：「平安」→ 两个按钮「中国平安 / 平安银行」，不再默认猜一个 | M5 测试里 6/6 次都猜成中国平安 | 新做（已知问题） |
| **默认口径，不让用户填**：年报、合并报表、加权 ROE 作为默认，并在摘要里写明 | 用户不懂或懒得选口径 | 部分已有 |
| **在图上直接改**：点掉一家、加一家、框选年份，立即出新图并生成新数据集 | 不用再问一遍、再等一轮 | 新做（加 / 去公司、截年份的变换已在 shared 里） |
| **可点的追问**：「加同行对照」「换季度」「看利润率」 | 不知道下一步问什么 | 新做 |

## 2. 清晰：一眼看懂、看得出能不能信

| 交互 | 解决什么 | 状态 |
|---|---|---|
| **结论当标题**：图的标题由代码按数据生成，例如「公司甲 ROE 连续 2 年上升，2024 年为六年最高」 | 看图不知道重点 | 新做（「变化最大的年份」已有，可扩成几条规则） |
| **数字即引用**：每个数字可点，看报告期、口径、取数时间 | 不知道能不能信 | 已有（图上），要扩到正文与指标卡 |
| **覆盖格子**：公司 × 年份的小格子，缺的格子标琥珀色 | 不知道哪些数缺了 | 新做 |
| **口径冲突才提示**：只在两家公司口径不一致时出现提示与切换，不常驻 | 口径混用而不自知 | 新做（替代之前「口径开关常驻」的想法，更清楚） |
| **一屏一件事**：结论、指标卡、主图、证据，其余收起 | 信息堆在一起 | 见 `design-review.md` |

## 3. 辅助决策：回答「所以呢」，但不替用户下单

原则：**事实与对比由代码算，解读由模型写但只能引用算好的事实；不给买卖建议。**

| 交互 | 帮用户判断什么 | 状态 |
|---|---|---|
| **同行位置**：自动给出行业中位数和分位，例如「毛利率高于行业 80% 的公司」 | 好还是不好，是相对的 | 新做（行业分类数据已有，需新增同行取数） |
| **趋势信号**：连续上升 / 下降几年、拐点、波动是否异常，全部规则计算 | 是在变好还是变坏 | 新做 |
| **变化拆解**：净利率上升是因为毛利率还是费用；ROE 是靠盈利还是靠加杠杆 | 变化背后的原因 | 部分可做（毛利率、净利率已有；周转率、杠杆率指标需新增） |
| **值得注意清单**：把上面信号里最突出的 2–3 条列出来，每条带数字和来源 | 先看什么 | 新做 |
| **跟踪点**：把一张图钉住时可以加「毛利率跌破 X% 时提醒我」，新财报到来时检查 | 不用自己盯 | 新做（看板、公告数据已有） |
| **边界说明**：结尾固定一句「以上为历史数据对比，不构成投资建议」 | 合规与预期管理 | 新做 |

## 4. 和通用 AI 的区别，用用户的话说

- **问得更省事**：从自己的自选股点进去，有歧义时点一下就选好，图上直接改，不用重新组织问题。
- **看得更明白**：标题就是结论，缺什么、什么口径一眼看到。
- **信得过**：每个数都能点开核对，同一个问题问两次结果一样。
- **帮得上忙**：告诉你它在同行里的位置、在变好还是变坏、原因是什么，但不替你做买卖决定。

## 5. 建议先做的三件事

1. **结论当标题 + 值得注意清单**（辅助决策，最能体现价值；只需规则计算，不需新数据源）。
2. **在图上直接改**（便利，最能在头几秒让用户感到不同）。
3. **歧义一键选**（便利，修掉 M5 里的已知问题）。

同行位置、变化拆解、跟踪提醒需要新增数据或指标，排在后面，并按 AGENTS.md 先出方案。
