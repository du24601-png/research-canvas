# 专业个人投资者：日常核心场景、现用工具与问题（2026-10-10）

**说明**：本文基于公开资料、各工具的官网介绍和产品常识推断，**不是用户访谈结论**。公开资料里几乎找不到 2026 年国内个人投资者研究痛点的可靠调研，建议用 6–8 次访谈验证下面的判断（访谈提纲见文末）。

## 是谁

自己做基本面研究的 A 股个人投资者：持仓 5–20 只，看财报、做比较、记笔记，愿意为数据工具付少量费用（参照：理杏仁、问财会员）。不是天天打板的短线用户。

## 日常核心场景（按频率）

| # | 场景 | 频率 | 典型动作 |
|---|---|---|---|
| 1 | **跟踪持仓 / 自选** | 每天–每周 | 看价格和公告；财报季逐家看「这季怎么样」 |
| 2 | **财报季速读** | 每季集中爆发 | 营收、利润、毛利率、现金流同比环比；和自己预期、和同行比 |
| 3 | **研究一家新公司** | 每周几次 | 近五到十年的核心财务指标、商业模式、同行对比 |
| 4 | **估值判断** | 持续 | PE / PB 历史分位、和同行比、和自己的买入逻辑比 |
| 5 | **同行比较 / 选标的** | 每周 | 一个行业里谁的盈利能力、增长、估值更好 |
| 6 | **核对一个说法** | 随时 | 雪球、公众号里看到一个数字或结论，去核实 |
| 7 | **记录与复盘** | 每周–每月 | 投资笔记、逻辑是否被证伪、仓位调整理由 |

## 现在用什么工具

| 工具 | 用来做什么 | 主要问题 |
|---|---|---|
| 同花顺 / 东方财富 App 与 PC | 行情、F10 财务、公告、问财 / 妙想 | 数据在多个页面；口径说明不清；AI 回答无法核对 |
| 理杏仁 | 基本面数据、估值分位、自定义图表 | 官网自述上手门槛高；深度功能需付费；不负责解释 |
| 巨潮资讯网 | 公告与年报原文 | 只能读 PDF，找数靠翻页 |
| 雪球 | 社区讨论、观点、投资日历 | 信息噪音大，真假难辨 |
| Excel / 表格 | 自建对比表、模型 | 手抄数据、维护成本高、容易出错 |
| 笔记工具（Notion、印象笔记等） | 投资逻辑、复盘 | 和数据脱节，数字是手抄的 |
| 通用 AI（豆包、Kimi、ChatGPT 等） | 读年报、问概念、写总结 | 数字不可信，需要逐个回原文核对 |

## 共性问题（推断）

1. **数据散**：一个问题要开 3–5 个页面（F10、公告原文、估值站、社区）。
2. **口径乱**：不同平台同一指标数字不同（年报 / TTM、合并 / 母公司、加权 / 摊薄），说不清为什么。
3. **比较难**：多家多年对齐要靠 Excel 手工。
4. **不可信**：AI 和社区给的数不知道从哪来，核对成本高。
5. **难沉淀**：结论和数字分离，复盘时找不回当初的依据。

## 对 FinFrame 的含义

| 场景 | FinFrame 能做的 | 现状 |
|---|---|---|
| 财报季速读 | 「看看 XX 这季」→ 关键指标变化 + 要点 + 来源 | 年度数据已有；**季度数据与「较上季」需补** |
| 研究新公司 | 个股速览页 | 已做（5 个指标） |
| 同行比较 | 对比图 + 数值表 + 差距结论 | 已做；同行名单确认已有 |
| 核对一个说法 | 查数快路 + 来源与口径 | 来源已有；**快路待做** |
| 估值判断 | PE / PB 历史分位 | **未做**（缺估值指标） |
| 记录与复盘 | 看板 + 版本 | 已有雏形；**「上次以来变了什么」未做** |
| 跟踪持仓 | 自选 / 持仓数据已有 | **未和研究打通** |

优先补：季度数据与财报季速读、估值分位、查数快路。

## 访谈提纲（验证用）

1. 最近一次认真研究一家公司，从哪开始、开了哪些页面、花了多久？
2. 财报季你怎么看持仓公司的财报？最烦的一步是什么？
3. 遇到过不同平台数字对不上吗？你怎么处理？
4. 用过 AI 查财务数据吗？信不信？为什么？
5. 你的研究结论记在哪？复盘时能找回当时的数据吗？
6. 现在为哪些数据或工具付费？多少钱？为什么值？
